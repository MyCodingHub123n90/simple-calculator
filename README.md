# Simple Calculator

A simple and elegant calculator built with HTML, CSS, and JavaScript.

## Features

- ✅ Basic arithmetic operations (addition, subtraction, multiplication, division)
- ✅ Decimal point support
- ✅ Clear (C) button to reset the calculator
- ✅ Delete (DEL) button to remove the last digit
- ✅ Responsive design that works on mobile and desktop
- ✅ Modern UI with gradient background and smooth animations
- ✅ Error handling for division by zero

## How to Use

1. Open `index.html` in your web browser
2. Click the number buttons to enter numbers
3. Click an operator button (+, −, ×, ÷) to select an operation
4. Enter the second number
5. Click the = button to get the result
6. Use C to clear the display and start over
7. Use DEL to remove the last digit

## Files

- `index.html` - HTML structure of the calculator
- `style.css` - Styling and responsive layout
- `script.js` - Calculator logic and functionality

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with flexbox and grid
- **JavaScript** - Calculator logic and event handling
